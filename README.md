Программа нахождения обратной матрицы с помощью метода вращений
Я использую QR разложение специального вида, где данные об обеих матрицах Q и R хранятся в одной матрице, где на диагонали и выше хранятся значения R, а в остальных клетках стоят косинусы углов матриц поворота, которые обнуляют соответствующую клетку и при умножении в определенном порядке дают Q. Далее я использую эти данные, чтобы решить матричное уравнение AX=E.

Сборка: make all

Очистка: make clean

Запуск: ./a.out n m k filename (или ./a.exe ...)
